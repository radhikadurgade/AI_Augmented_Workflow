# AI Augmented Workflow

## Objective
To build a simple conversational AI agent and document the use of AI tools during development.

## Tools Used
- Visual Studio Code
- Python 3.12 or newer
- Git
- GitHub
- GitHub Copilot

## AI Tool Used
GitHub Copilot and ChatGPT were used for coding assistance and guidance.

## How to Run
1. Install Python 3.12 or newer.
2. Open the project folder in Visual Studio Code.
3. Open `agent.py`.
4. Run the Python file.
5. Enter messages in the terminal.
6. Type `bye` to exit the agent.

## Features
- Simple conversational interaction
- Greeting response
- Name response
- Exit command using `bye`
- Unknown input handling
